# From raw intracranial EEG to channel inspection

This guide introduces the Neuralynx intracranial EEG (iEEG) data used in the GMNUM project. It is intended for someone new to iEEG, epilepsy research, and Neuralynx files.

The goals are to understand the files and channel names, open signals and events safely, extract metadata without loading a whole recording, verify that channels are compatible, and interpret the channel-quality metrics produced by the project.

An automated inspection flag is **not an automatic exclusion decision**. Epileptic activity is often unusual by definition and can resemble artifact in amplitude, frequency content, or spatial correlation. Review raw traces, anatomy, events, and clinical annotations before excluding a channel.

## 1. What is intracranial EEG?

iEEG records electrical activity from electrodes placed inside the skull. It has higher spatial resolution than scalp EEG because the electrodes are closer to neural sources.

- **Depth electrodes / stereo-EEG (SEEG):** a thin shaft, or “stick,” carries several contacts through deep and cortical structures. A stick often has around 8 contacts, but this varies.
- **ECoG grids or strips:** contacts rest on the cortical surface.
- **Microelectrodes:** smaller electrodes can record very local field potentials and, depending on the acquisition, action potentials.
- **Scalp EEG:** electrodes on the scalp; these are not intracranial channels even when recorded alongside iEEG.

The continuous signal in `.ncs` files is usually interpreted as a local field potential or iEEG signal. It is not the same as a sorted single-neuron spike train.

### Epilepsy terms used during inspection

- **Ictal:** during a seizure.
- **Interictal:** between seizures. Interictal epileptiform discharges can include spikes and sharp waves.
- **Pre-ictal / post-ictal:** before / after a seizure.
- **Epileptogenic zone:** tissue considered necessary for generating seizures. Its definition is clinical and cannot be inferred from one signal metric.
- **Artifact:** signal not generated by the neural process of interest, such as movement, poor contact, amplifier saturation, mains interference, or acquisition failure.
- **Reference:** the electrode or signal against which a channel voltage is measured. Re-referencing can strongly change amplitude, correlation, and spectral metrics.

```python
import re

def split_contact_name(channel_name):
    match = re.fullmatch(r"(.+?)(\d+)", channel_name)
    if match is None:
        return channel_name, None
    return match.group(1), int(match.group(2))

print(split_contact_name("LPHC2"))  # ('LPHC', 2)
```

## 3. Files in a Neuralynx subject-session

| Extension | Contents | Use here |
| --- | --- | --- |
| `.ncs` | One continuously sampled signal channel | Raw iEEG for one contact |
| `.nev` | Timestamped events, IDs, TTL values, and labels | Align tasks, triggers, annotations, and recording events |
| `.nse` | Spike waveforms from a single electrode | Not part of current continuous-channel inspection |
| `.ntt` | Spike waveforms from a tetrode | Not part of current continuous-channel inspection |

Neo supports these formats through `NeuralynxRawIO`. See the official [Neo NeuralynxRawIO documentation](https://neo.readthedocs.io/en/stable/rawiolist.html#neo.rawio.NeuralynxRawIO) and [Neo RawIO API](https://neo.readthedocs.io/en/stable/rawio.html).

### NCS structure

The official [Neuralynx data-file format specification](https://neuralynx.com/_software/NeuralynxDataFileFormats.pdf) states that a file begins with a **16 KiB ASCII header**, followed by binary records.

A conventional NCS record contains:

- the timestamp of its first sample in microseconds;
- channel number;
- sampling frequency;
- number of valid samples; and
- an array holding up to 512 signed 16-bit samples.

Do not confuse these values:

- **16 KiB** is the file-header size;
- **512** is the maximum sample count in a conventional record.

The final record may legitimately contain fewer than 512 valid samples. That alone does not prove corruption. Header fields can vary between Cheetah versions, so do not hard-code a fixed list of header strings.

### Basic integrity check

A file smaller than the header cannot be a complete conventional Neuralynx file. Common NCS records are 1,044 bytes, so their payload is normally a whole number of records. Parsing and timestamp checks are still required.

```python
from pathlib import Path

ncs_path = Path("/path/to/session/CSC1.ncs")
header_bytes = 16 * 1024
common_record_bytes = 1044
file_bytes = ncs_path.stat().st_size

if file_bytes < header_bytes:
    raise ValueError("File is smaller than the Neuralynx header")

payload_bytes = file_bytes - header_bytes
print("Whole records:", payload_bytes // common_record_bytes)
print("Remaining bytes:", payload_bytes % common_record_bytes)
```

This cannot detect every problem. Also verify that Neo parses the folder, expected channels exist, timestamps are sensible, and durations agree across channels.

## 4. Reading Neuralynx data with Neo

GMNUM uses Neo 0.14.5 in the `ieeg` Conda environment. Neo reads in chunks, which prevents high-rate recordings from filling memory.

```bash
conda install -c conda-forge python-neo
```

Documentation:

- [Neo installation](https://neo.readthedocs.io/en/stable/install.html)
- [Reading and analyzing data with Neo](https://neo.readthedocs.io/en/stable/read_and_analyze.html)
- [RawIO chunk-reading API](https://neo.readthedocs.io/en/stable/rawio.html)
- [NeuralynxRawIO class](https://neo.readthedocs.io/en/stable/rawiolist.html#neo.rawio.NeuralynxRawIO)

### Open the complete session folder

Pass the directory, not just one NCS file, when signals and events should be discovered together.

```python
from pathlib import Path
from neo.rawio import NeuralynxRawIO

session_directory = Path("/path/to/subject-session")
reader = NeuralynxRawIO(
    dirname=str(session_directory),
    keep_original_times=False,
    strict_gap_mode=True,
)
reader.parse_header()

print(reader)
print("Segments:", reader.segment_count(0))
print("Signal streams:", reader.header["signal_streams"])
print("Signal channels:", reader.header["signal_channels"])
print("Event channels:", reader.header["event_channels"])
```

- `keep_original_times=False` makes session time start around zero and simplifies signal/event plotting.
- `keep_original_times=True` retains the original Neuralynx time reference.
- `strict_gap_mode=True` detects a gap when records differ by more than one sample interval.
- `strict_gap_mode=False` is more tolerant and may help with clock deviations; do not use it merely to hide unexplained gaps.

Neo may create multiple segments when recording stops/restarts or timestamps are discontinuous. Never assume one continuous segment.

### Metadata available through Neo

`reader.header["signal_channels"]` gives each channel's:

- name and ID;
- sampling rate;
- stored data type, commonly `int16`;
- physical unit, commonly `uV` after scaling;
- gain and offset; and
- stream and buffer IDs.

`reader.header["signal_streams"]` identifies compatible channel groups. Different acquisition properties can create multiple streams.

`reader.file_headers` exposes parsed per-file metadata. Depending on recording version, this can include:

- original filename;
- file type/version;
- channel name/ID;
- sampling rate;
- input range and maximum ADC value;
- bit-to-microvolt conversion and inversion;
- low-cut/high-cut filters and filter delay;
- acquisition software/hardware;
- recording opened/closed times; and
- record size.

Not every file has every field:

```python
for source_path, parsed_header in reader.file_headers.items():
    source_path = Path(source_path)
    if source_path.suffix.lower() != ".ncs":
        continue

    header = dict(parsed_header)
    print("\nFile:", source_path.name)
    print("Available fields:", sorted(header))
    for key in (
        "OriginalFileName", "channel_names", "channel_ids",
        "sampling_rate", "bit_to_microVolt", "InputRange",
        "DSPLowCutFilterEnabled", "DspLowCutFrequency",
        "DSPHighCutFilterEnabled", "DspHighCutFrequency",
        "recording_opened", "recording_closed",
    ):
        if key in header:
            print(f"  {key}: {header[key]}")
```

The header describes settings and provenance. It does not prove that a signal is physiologically valid.

### Read and plot a short window

`get_analogsignal_chunk()` returns raw ADC values. Scale them before interpreting amplitude. Check `units` rather than assuming microvolts.

```python
import matplotlib.pyplot as plt
import numpy as np

stream_index = 0
segment_index = 0
channel_name = "LA1"
start_seconds = 10.0
duration_seconds = 5.0

stream = reader.header["signal_streams"][stream_index]
mask = reader.header["signal_channels"]["stream_id"] == stream["id"]
stream_channels = reader.header["signal_channels"][mask]
names = [str(name) for name in stream_channels["name"]]
local_index = names.index(channel_name)
sampling_rate = float(stream_channels[local_index]["sampling_rate"])
signal_t_start = float(reader.get_signal_t_start(0, segment_index, stream_index))

i_start = int(round(start_seconds * sampling_rate))
i_stop = i_start + int(round(duration_seconds * sampling_rate))
raw = reader.get_analogsignal_chunk(
    block_index=0, seg_index=segment_index,
    i_start=i_start, i_stop=i_stop,
    stream_index=stream_index, channel_indexes=[local_index],
)
signal_uv = reader.rescale_signal_raw_to_float(
    raw, dtype="float32", stream_index=stream_index,
    channel_indexes=[local_index],
)[:, 0]
times = signal_t_start + np.arange(i_start, i_stop) / sampling_rate

fig, axis = plt.subplots(figsize=(12, 4))
axis.plot(times, signal_uv, color="black", linewidth=0.6)
axis.set(xlabel="Neo time (s)", ylabel="Signal (µV)", title=channel_name)
plt.show()
```

For full-session calculations, loop over chunks instead of loading everything at once.

### Recording duration

Acquired duration is sample count divided by sampling rate. Wall-clock span can be longer when gaps exist.

```python
stream_index = 0
stream = reader.header["signal_streams"][stream_index]
mask = reader.header["signal_channels"]["stream_id"] == stream["id"]
sampling_rate = float(reader.header["signal_channels"][mask][0]["sampling_rate"])

durations = []
for segment_index in range(reader.segment_count(0)):
    samples = reader.get_signal_size(0, segment_index, stream_index)
    durations.append(samples / sampling_rate)

print("Segment durations (s):", durations)
print("Acquired duration (min):", sum(durations) / 60)
```

### Read NEV events

Events are session-level information. They can contain a timestamp, event ID, TTL value, and label. TTL meanings are experiment-specific.

```python
import pandas as pd

event_rows = []
segment_index = 0
for event_channel_index, event_channel in enumerate(reader.header["event_channels"]):
    raw_timestamps, _, labels = reader.get_event_timestamps(
        block_index=0, seg_index=segment_index,
        event_channel_index=event_channel_index,
    )
    event_times = reader.rescale_event_timestamp(
        raw_timestamps, dtype="float64",
        event_channel_index=event_channel_index,
    )
    for event_time, raw_timestamp, label in zip(
        event_times, raw_timestamps, labels, strict=True
    ):
        event_rows.append({
            "event_channel": str(event_channel["name"]),
            "time_seconds": float(event_time),
            "raw_timestamp_us": int(raw_timestamp),
            "label": str(label),
        })

events = pd.DataFrame(
    event_rows,
    columns=["event_channel", "time_seconds", "raw_timestamp_us", "label"],
).sort_values("time_seconds")
print(events.head())
```

Neo event-channel names can include values such as `event_id=11 ttl=4`:

```python
import re

def event_value(name, field):
    match = re.search(fr"{field}=(\d+)", name)
    return int(match.group(1)) if match else None

events["event_id"] = events["event_channel"].map(
    lambda name: event_value(name, "event_id")
)
events["ttl"] = events["event_channel"].map(
    lambda name: event_value(name, "ttl")
)
```

Signals and events must use the same reader and time convention before overlaying them.

Check parsed `recording_opened`/`recording_closed`, `keep_original_times`, first signal/event timestamps, experimental logs, and known task-event alignment. ## 5. Checks before combining channels

Before creating one multichannel representation, confirm:

1. channel names are unique;
2. sampling rates match or resampling is explicit;
3. data types, gains, offsets, and units are understood;
4. streams have matching start time and sample count per segment;
5. segment/gap structure is compatible;
6. event times share the same time reference; and
7. source and original filenames remain recorded.

Do not assume every channel belongs to stream 0.

```python
import numpy as np

channels = reader.header["signal_channels"]
streams = reader.header["signal_streams"]
names = [str(name) for name in channels["name"]]
if len(names) != len(set(names)):
    raise ValueError("Channel names are not unique")

rates = np.unique(channels["sampling_rate"].astype(float))
if len(rates) != 1:
    raise ValueError(f"Multiple sampling rates: {rates.tolist()}")

for segment_index in range(reader.segment_count(0)):
    sizes = [reader.get_signal_size(0, segment_index, i) for i in range(len(streams))]
    starts = [reader.get_signal_t_start(0, segment_index, i) for i in range(len(streams))]
    if len(set(sizes)) != 1 or not np.allclose(starts, starts[0], atol=1e-6):
        raise ValueError(f"Streams are not aligned in segment {segment_index}")
```

## 6. GMNUM channel inspection

`GMNUM/src/inspection.py` processes every subject-session in `num_new` and writes `channel_metrics_inspection.csv` in each session folder.

```bash
cd /path/to/GMNUM
conda run -n ieeg python src/inspection.py
```

Existing CSVs are skipped. Recompute with `--overwrite`. The raw files are read-only and processed in chunks.

Each CSV row is one channel and includes identity, stick/contact, stream and filename provenance, sampling and duration, quality metrics, robust outlier scores, `inspection_reasons`, and the final Boolean `inspection`.

### Calculation settings

- Variance, peak-to-peak, exact flat-sample proportion, and neighbor correlations use all original samples.
- MAD uses a uniform full-session sample after anti-aliased resampling.
- PSD data are anti-alias filtered and resampled to 1,024 Hz.
- PSD uses four-second Hann windows with 50% overlap and 0.25 Hz resolution.
- Broadband power covers 1–250 Hz.
- European line-noise bands are ±1 Hz around 50, 100, 150, 200, and 250 Hz.

## 7. Metrics: why they are computed and what they may mean

No single metric diagnoses a bad channel. Compare contacts on the same stick and interpret metrics together.

| Metric | Calculation and purpose | High/unusual may indicate | Low/unusual may indicate |
| --- | --- | --- | --- |
| **Variance (`variance_uv2`)** | Mean squared deviation from the mean; overall variability | Strong physiology, seizure activity, movement, broadband noise, transients, saturation | Attenuation, disconnection, quiet contact, flat signal |
| **MAD (`mad_uv`)** | Median absolute deviation; robust typical amplitude | Persistently large activity or noise | Persistently small/attenuated signal |
| **Peak-to-peak (`peak_to_peak_uv`)** | Full-session maximum minus minimum; detects extremes | Electrode pop, movement, seizure discharge, clipping/saturation | Restricted dynamic range; interpret with MAD/variance |
| **Flat samples (`flat_sample_percent`)** | Exactly equal consecutive raw ADC samples | Disconnection, digital freezing, plateaus, severe quantization | Usually expected; low is not itself a problem |
| **Neighbor correlation (`mean_neighbor_correlation`)** | Mean Pearson correlation with adjacent contacts on the stick | Shared signal/reference/artifact; current rule does not flag high values | Isolated contact, poor contact, focal physiology, different anatomy, channel-specific artifact |
| **Broadband power (`broadband_1_250_hz_power_uv2`)** | Integrated PSD from 1–250 Hz | Broadband artifact, high-amplitude physiology, seizure activity | Attenuated or nearly silent channel |
| **PSD deviation (`psd_deviation_median_abs_db`)** | Median absolute dB difference from stick-median PSD | Narrow/broadband noise, different tissue, focal activity, acquisition difference | Spectrum similar to stick |
| **Total line power (`line_noise_total_power_uv2`)** | Sum near 50–250 Hz harmonics | Electrical interference, ground/shield/reference/impedance issue | Little absolute mains contamination |
| **Line ratio (`line_noise_ratio_percent`)** | Harmonic power divided by 1–250 Hz power | Mains interference dominates relative to signal | Harmonics are a small fraction of power |
| **Individual harmonic powers** | Power ±1 Hz around each harmonic | A specific narrow-band interference peak | Little power at that harmonic |

### Why variance and MAD?

Variance is very sensitive to extreme samples; MAD reflects typical amplitude. High peak-to-peak and variance with ordinary MAD suggests a few large transients. High variance and high MAD indicate more persistent elevation.

### Why PSD?

PSD describes power by frequency in µV²/Hz. A narrow 50 Hz peak suggests mains interference. Broad elevation can indicate noise, movement, or strong physiology. Excess low-frequency power can reflect drift, movement, slow physiology, or seizure activity. Interpretation must consider acquisition filters in the NCS header; removed frequencies cannot be recovered.

### Why neighboring-contact correlation?

Nearby contacts often share some local and reference-related signal. Low correlation can reveal a noisy/isolated contact, but may also reflect different tissue or focal epileptic activity. Reference choice strongly affects correlation.

## 8. Robust within-stick outliers

Contacts are compared with others on the same stick because normal amplitude and spectrum differ across regions and electrode types.

```text
robust_z = 0.67448975 × (x - stick median) / stick MAD
```

If MAD is zero/unstable, the script falls back to an IQR-derived scale and then standard deviation. Threshold: 3.5.

- **Two-sided:** variance, MAD, peak-to-peak, broadband power.
- **High only:** flat percentage, PSD deviation, total line power, line ratio, and each harmonic.
- **Low only:** neighboring-contact correlation.

The CSV has `<metric>_robust_z` and `<metric>_outlier` for every test. `inspection_reasons` lists positive tests; `inspection` is `True` if any test is positive. Small sticks provide a weak reference distribution, so the score is a screening aid, not a probability that a channel is bad.

```python
import pandas as pd

inspection = pd.read_csv(
    session_directory / "channel_metrics_inspection.csv"
)
flagged = inspection.loc[
    inspection["inspection"],
    ["channel", "stick", "inspection_reasons"],
]
print(flagged)

reason_counts = (
    inspection.loc[inspection["inspection"], "inspection_reasons"]
    .str.split("; ").explode().value_counts()
)
print(reason_counts)
```

## 9. Interpreting metric combinations

| Pattern | Possible explanation | Inspect next |
| --- | --- | --- |
| High flatness + low variance/MAD | Disconnected, frozen, attenuated, quantized | Raw trace at several times; timestamps; acquisition notes |
| High peak-to-peak/variance + ordinary MAD | Rare transient/electrode pop | Windows around extrema; events; other channels |
| High variance + MAD + broadband power | Persistent high-amplitude physiology or contamination | Seizure timing, anatomy, reference, neighbors |
| High line ratio + 50 Hz harmonics | Mains contamination dominates | Ground/reference, impedance, neighbors, notch policy |
| High absolute line power + ordinary ratio | Large signal with non-dominant line noise | PSD and broadband amplitude together |
| Low neighbor correlation + high PSD deviation | Isolated channel or focal phenomenon | Electrode location, raw trace, clinical annotations |
| Neighboring contacts change together | Regional physiology, shared artifact, reference effect | Other sticks, events, reference, clinical context |

These are hypotheses, not diagnoses.

## 10. Recommended workflow

1. Confirm expected NCS channels, NEV, original filenames, and channel map.
2. Parse with Neo; record version/options, streams, segments, rates, units, and filters.
3. Verify alignment before combining channels.
4. Confirm event alignment and time reference.
5. Run `inspection.py`.
6. Read each flagged channel's reasons and compare it within its stick.
7. Inspect raw traces at several times; one clean window is insufficient.
8. Inspect PSD, line harmonics, and neighboring contacts.
9. Use anatomy and clinical information, including seizure-onset annotations.
10. Document whether the channel is kept, re-referenced, conditionally used, or excluded, with reviewer and reason.

`GMNUM/src/exploration.ipynb` provides cohort summaries plus interactive raw-time and full-session PSD browsers.
